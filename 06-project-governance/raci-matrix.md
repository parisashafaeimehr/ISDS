# RACI Responsibility Matrix

## Purpose

This matrix clarifies responsibilities across the AI product lifecycle.

## RACI Definitions

- **R — Responsible:** Performs the work.
- **A — Accountable:** Owns the outcome and final decision. Each activity should normally have one A.
- **C — Consulted:** Provides input before a decision or action.
- **I — Informed:** Receives updates.

## Governance Rules

1. Assign named individuals to the roles before project execution.
2. Review the matrix at project kickoff and whenever scope changes.
3. Ensure every activity has one clearly identified accountable owner.
4. Add or remove roles based on the project context.
5. Resolve conflicts between roles before work begins.

## Important Note

This is a reference matrix. The project team must validate and adjust assignments before using it operationally.

# فهرست فرصت‌های بازار هوش مصنوعی

## ۱. هدف

این سند محل ثبت، پیگیری و مدیریت تمام فرصت‌های شناسایی‌شده برای توسعه بازار و تجاری‌سازی محصولات هوش مصنوعی ISDS است.

هر فرصت باید شناسه یکتا داشته باشد و از مرحله شناسایی تا اعتبارسنجی، طراحی پایلوت، تصمیم‌گیری و تجاری‌سازی قابل پیگیری باشد.

## ۲. مراحل چرخه عمر فرصت

| مرحله | عنوان | شرط ورود | خروجی مورد انتظار |
|---|---|---|---|
| S01 | شناسایی‌شده | مسئله یا فرصت اولیه ثبت شده است | شرح اولیه فرصت |
| S02 | در حال بررسی | اطلاعات پایه فرصت موجود است | شناخت اولیه مشتری، مسئله و راهکار |
| S03 | اعتبارسنجی بازار | فرضیه اولیه قابل بررسی است | شواهد تقاضا و بازخورد مشتری |
| S04 | ارزیابی فنی و اقتصادی | مسئله و مشتری بالقوه شناسایی شده‌اند | ارزیابی امکان‌پذیری و ارزش اقتصادی |
| S05 | اولویت‌بندی‌شده | امتیازدهی و بررسی موانع انجام شده است | تصمیم درباره اولویت و اقدام بعدی |
| S06 | طراحی پایلوت | فرصت برای آزمون محدود تأیید شده است | دامنه، برنامه و معیارهای موفقیت پایلوت |
| S07 | اجرای پایلوت | منابع و مجوزهای لازم فراهم شده‌اند | نتایج مستند پایلوت |
| S08 | تصمیم تجاری‌سازی | نتایج پایلوت ارزیابی شده‌اند | تصمیم توسعه، اصلاح یا توقف |
| S09 | در حال تجاری‌سازی | تصمیم توسعه گرفته شده است | راهکار قابل عرضه و برنامه ورود به بازار |
| S10 | متوقف‌شده | فرصت متوقف یا رد شده است | دلیل توقف و شرایط احتمالی بازگشت |

## ۳. قالب ثبت فرصت

برای هر فرصت، اطلاعات زیر ثبت شود:

| فیلد | توضیح |
|---|---|
| Opportunity ID | شناسه یکتا مانند OP-001 |
| عنوان فرصت | نام کوتاه و قابل فهم |
| صنعت | صنعت هدف |
| بخش یا زیرصنعت | حوزه دقیق‌تر مشتری |
| مشتری هدف | سازمان یا گروه مشتری بالقوه |
| مسئله مشتری | مسئله واقعی که باید حل شود |
| کاربر اصلی | فرد یا تیم استفاده‌کننده |
| تصمیم‌گیر اقتصادی | فرد یا واحد دارای اختیار بودجه |
| خانواده کاربرد | شناسه از کاتالوگ کاربردها |
| محصول پیشنهادی | محصول یا محصولات مرتبط ISDS |
| راهکار پیشنهادی | شرح کوتاه راهکار |
| ارزش مورد انتظار | صرفه‌جویی، افزایش درآمد یا بهبود عملکرد |
| شواهد بازار | مصاحبه، درخواست مشتری، داده یا سند |
| امتیاز نهایی | امتیاز طبق مدل اولویت‌بندی |
| سطح اطمینان | پایین، متوسط یا بالا |
| موانع اصلی | داده، امنیت، قانون، فنی یا تجاری |
| مالک فرصت | فرد مسئول پیگیری |
| وضعیت | مرحله فعلی چرخه عمر |
| اقدام بعدی | اقدام مشخص و قابل پیگیری |
| موعد اقدام بعدی | تاریخ هدف |
| تاریخ آخرین به‌روزرسانی | زمان آخرین بررسی |

## ۴. قواعد مدیریت فهرست

1. پیش از ایجاد فرصت جدید، فرصت‌های مشابه بررسی شوند تا از ثبت تکراری جلوگیری شود.
2. هر فرصت باید یک مالک مشخص داشته باشد.
3. فرصت بدون اقدام بعدی و مسئول پیگیری نباید در وضعیت فعال باقی بماند.
4. دلایل توقف یا رد فرصت ثبت شوند.
5. امتیاز فرصت با ورود شواهد جدید به‌روزرسانی شود.
6. فرصت‌های مشابه در چند صنعت باید از نظر قابلیت تکرار و نیازهای اختصاصی مشتری بررسی شوند.
7. ثبت فرصت به معنی تأیید توسعه محصول یا تخصیص بودجه نیست.

## ۵. گزارش مدیریتی فهرست فرصت‌ها

گزارش دوره‌ای باید حداقل شامل این موارد باشد:

- تعداد فرصت‌ها در هر مرحله
- فرصت‌های دارای بالاترین امتیاز
- فرصت‌های متوقف‌شده و دلایل توقف
- فرصت‌های دارای مشتری علاقه‌مند
- فرصت‌های آماده طراحی پایلوت
- فرصت‌های در معرض ریسک
- اقدامات عقب‌افتاده
- تصمیم‌های موردنیاز از مدیریت

## ۶. اصل تصمیم‌گیری

هدف، افزایش تعداد فرصت‌ها نیست؛ هدف، شناسایی فرصت‌هایی است که مسئله واقعی مشتری، ارزش اقتصادی، امکان اجرا و قابلیت تجاری‌سازی آن‌ها با شواهد کافی پشتیبانی شود.

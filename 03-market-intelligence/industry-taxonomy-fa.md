# طبقه‌بندی صنایع هدف

## هدف

این سند یک طبقه‌بندی اولیه برای شناسایی بازارهای هدف و تحلیل فرصت‌های محصولات هوش مصنوعی ISDS ارائه می‌کند.

## خانواده‌های صنعتی

| شناسه | صنعت | نمونه زیرصنایع |
|---|---|---|
| I01 | انرژی و منابع طبیعی | نفت، گاز، برق، انرژی تجدیدپذیر |
| I02 | معدن و فلزات | معدن، فولاد، مس، فرآوری مواد معدنی |
| I03 | تولید و صنایع کارخانه‌ای | تولید صنعتی، ماشین‌آلات، خودروسازی |
| I04 | داروسازی و زیست‌فناوری | داروسازی، زیست‌فناوری، کشف دارو |
| I05 | سلامت و درمان | بیمارستان، کلینیک، آزمایشگاه پزشکی |
| I06 | بانکداری و خدمات مالی | بانک، سرمایه‌گذاری، خدمات پرداخت |
| I07 | بیمه | بیمه عمر، سلامت، اموال و کسب‌وکار |
| I08 | تجارت و خرده‌فروشی | خرده‌فروشی، عمده‌فروشی، تجارت الکترونیک |
| I09 | لجستیک و حمل‌ونقل | حمل بار، انبارداری، مدیریت ناوگان |
| I10 | فناوری و ارتباطات | نرم‌افزار، خدمات فناوری اطلاعات، مخابرات |
| I11 | دولت و بخش عمومی | سازمان‌های دولتی، شهرداری‌ها |
| I12 | آموزش و پژوهش | دانشگاه، مدرسه، مراکز تحقیقاتی |
| I13 | خدمات حرفه‌ای | مشاوره، حقوقی، حسابداری، مهندسی |
| I14 | ساخت‌وساز و املاک | ساخت‌وساز، مدیریت املاک |
| I15 | کشاورزی و صنایع غذایی | کشاورزی، تولید و فرآوری مواد غذایی |
| I16 | رسانه و صنایع خلاق | رسانه، تبلیغات، تولید محتوا |
| I17 | گردشگری و مهمان‌نوازی | هتل، سفر، رستوران |
| I18 | دفاع و زیرساخت‌های حساس | سازمان‌های دفاعی و زیرساخت‌های حیاتی |
| I19 | سازمان‌های غیرانتفاعی و عام‌المنفعه | سازمان‌های مردم‌نهاد، خیریه‌ها، نهادهای اجتماعی |

## معیارهای ارزیابی صنایع

- اهمیت و شدت مسائل کسب‌وکار
- بلوغ پذیرش هوش مصنوعی
- دسترس‌پذیری و کیفیت داده‌ها
- الزامات امنیتی و قانونی
- اندازه و ظرفیت رشد بازار
- امکان دسترسی به مشتریان بالقوه
- تناسب با سبد محصولات ISDS

## وضعیت

طبقه‌بندی اولیه است و باید بر اساس تحقیقات بازار، اولویت‌های تجاری و شواهد مشتریان بازنگری شود. قرار گرفتن یک صنعت در این فهرست به معنای تأیید تقاضای بازار نیست.
